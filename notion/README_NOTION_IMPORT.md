# Notion Import Guide

Use this folder as the working knowledge base seed for WholeRootLab.

## Recommended Notion Setup

1. Import `WholeRootLab_Digital_Materia_Medica_v0_1.md` as the main page.
2. Import `Monograph_Database.csv` as a database table.
3. Import or paste the files in `monographs/` as linked pages under the database entries.

## Suggested Database Properties

- `Herb`
- `Latin name`
- `Plant part`
- `Icelandic/Nordic relevance`
- `Evidence rating`
- `Primary safety caution`
- `Status`
- `Last reviewed`
- `Reference anchors`

## Editorial Rule

Every student-facing scientific claim should point to a named source in the reference section. Keep traditional use, modern evidence, and safety notes visibly separate.
